Billing questions

Can I try Pro features before paying?

Yes. On Free you can drag every weight slider and preview how the ranking changes; saving custom weights is what needs Pro.

What happens if I downgrade?

Nothing is deleted. Paid features lock (custom weights stop applying, webhooks pause) until you upgrade again, and extra aliases become read-only.

How do API limits work?

Requests are counted per workspace per UTC day. Responses carry X-RateLimit-Remaining; past the limit the API returns 429 until midnight UTC.

Do you offer discounts?

Yearly billing saves about 17%. Startups, open-source maintainers and researchers can ask us for a discount.
