How it works

From market noise to a routing decision

We collect the market

Prices from labs, OpenRouter endpoints and Nous Portal; benchmarks from Artificial Analysis, Epoch AI and LMArena. Unhealthy and 4-bit endpoints are excluded.

You describe your slots

Each alias has a budget, hard requirements (tools, reasoning, context) and weights for what matters. Start from presets in seconds.

Your agents call an alias

Point any OpenAI SDK at Modelfit and use the alias as the model name. We route, fail over and log every call; signed webhooks tell you when a route moves.

Model routing

Change one line. Every agent gets the best model.

Swap your base URL for Modelfit's and use your aliases as model names. Each request goes to the slot's current route, and to the next fallback if a provider errors or the model can't serve it.

  • OpenAI-compatible, streaming included: works with any SDK or agent framework
  • Sticky routes with a switch threshold, or pin a model outright
  • Fallbacks that respect tool calls and context length
  • Bring your own OpenRouter key: provider prices, zero markup

Questions

Where does the data come from?

Prices come from each lab's own endpoint, every provider endpoint on OpenRouter, Nous Portal and LiteLLM's price table. Benchmarks come from Artificial Analysis (via OpenRouter), the Epoch AI Benchmarking Hub and LMArena. All sources are cited and refreshed on their own schedules.

How is “fit” calculated?

Each benchmark is rescaled to 0–100 against today's purchasable models, averaged into four use-case scores, then weighted per alias. A missing benchmark is never counted as zero, and the app shows the full arithmetic for every number.

Is per-token price the whole story?

No — reasoning models spend more output tokens, so treat picks as a shortlist and check real task cost. Modelfit flags reasoning support and lets you switch the cost basis to input-only or output-only.

Do you proxy my traffic or mark up tokens?

The gateway forwards each request to the routed model with your own OpenRouter key, so you pay provider prices directly — we never add a margin. Prefer to keep traffic in your own gateway? Call /v1/routes/{alias} and route it yourself.

Can I self-host?

Yes. The same codebase runs as a single-user, self-hosted instance with every feature enabled — Python standard library only, no API keys required.
