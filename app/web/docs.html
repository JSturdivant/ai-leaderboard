API reference · v1

Modelfit API

Resolve your aliases to concrete models from your router, gateway or agent framework. Responses are JSON; model ids are OpenRouter-style (vendor/model).

Authentication

Create a key under Settings → API keys in the app and send it as a bearer token. Keys belong to a workspace and are shown once; revoke them any time.

shell
curl https://modelfit.ai/v1/recommendations \
  -H "Authorization: Bearer mf_live_…"

Gateway: route chat completions

POST/v1/chat/completions

OpenAI-compatible. Set model to one of your aliases (any case, optionally prefixed modelfit/) and Modelfit sends the request to that alias's current route. If the routed model errors (429, 5xx, timeouts, model unavailable) the next fallback is tried; models that cannot serve the request (tool calls on a model without tool use, a prompt larger than its context window) are skipped. Client errors (400) are returned as-is. Streaming ("stream": true) passes through.

Requests are forwarded with the OpenRouter key you connect under Routing in the app (encrypted at rest), so you pay provider prices directly. A concrete model id (vendor/model) passes straight through without fallbacks.

python
from openai import OpenAI

client = OpenAI(base_url="https://modelfit.ai/v1", api_key="mf_live_…")
reply = client.chat.completions.create(model="Coding", messages=[{"role": "user", "content": "Hi"}])
print(reply.model)        # the model that answered
print(reply.modelfit)     # {"alias": "Coding", "model": "…", "attempts": 1}

Routes: resolve an alias yourself

GET/v1/routes/{alias}?tools=1&context=60000

Already run your own gateway (LiteLLM, Portkey, an in-house router)? Ask which model an alias routes to and cache it for ttl_seconds. Optional tools and context narrow the answer to models that can serve that request. GET /v1/routes returns every alias.

200 OK
{ "alias": "Coding", "model": "anthropic/claude-opus-5.5", "mode": "auto",
  "reason": "holding: the top pick is only +0.8 fit (switch threshold 1)",
  "fit": 95.4, "since": 1795366000, "top_pick": "anthropic/claude-fable-5.2",
  "fallbacks": [{ "model": "google/gemini-4-neon", "fit": 95.2, … }],
  "ttl_seconds": 300, "version": 12 }

Why routes are sticky. Rankings move whenever prices or benchmarks do; your agents shouldn't. In auto mode a route switches only when a model beats the current one by the alias's switch threshold (default 1 fit point), or immediately when the current model stops being eligible or purchasable. Pinned routes always use one model (Pro). Every route change is logged and sent to your webhook as route.changed.

FieldMeaning
fit0–100: weighted average of the use-case scores with the alias's weights.
cost.blended$ per million tokens at the workspace cost basis (default 3 input : 1 output), cheapest channel.

One alias

GET/v1/recommendations/{alias}

The same entry for a single alias, plus alias and generated_at. 404 if the workspace has no such alias.

Models & market

GET/v1/models

OpenAI-compatible list of your aliases (so SDKs and agent frameworks can discover them), each with the model it routes to.

GET/v1/market?q=flash&limit=50

The market snapshot: every purchasable model with its lowest price and use-case scores (coding, agentic, reasoning, chat). q filters by id or name; limit is 1–500.

Webhooks Pro

Set a URL under Settings → Webhook. When an alias's route changes Modelfit POSTs a route.changed event; when its #1 pick changes, a picks.changed event. Same body shape:

POST your-url
{ "event": "picks.changed", "workspace": "ws_…", "generated_at": "…",
  "changed": { "Daily": { "from": "z-ai/glm-5.3-flash", "to": "deepseek/deepseek-v4.1-flash-1017" } } }

Verify it: X-Modelfit-Signature is v1= + hex HMAC-SHA256 of "{X-Modelfit-Timestamp}.{raw body}" with your webhook secret. Reject timestamps older than five minutes.

python
import hmac, hashlib, time

def verify(secret, ts, body, header):
    if abs(time.time() - int(ts)) > 300: return False
    want = "v1=" + hmac.new(secret.encode(), f"{ts}.".encode() + body, hashlib.sha256).hexdigest()
    return hmac.compare_digest(want, header)
