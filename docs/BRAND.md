# Brand

**Name:** Modelfit (wordmark lowercase: `model` + `fit` in the brand gradient).
**Promise:** the right model for every job, at the right price.
**Tagline options:** "Ship on the frontier, not on habit." · "Every slot, the best model its budget can buy."

## Mark

A rounded square in the brand gradient holding a white stepped line rising to a dot: the efficiency frontier
ending in the pick. Files: `app/web/assets/favicon.svg`; inline in every page header (`.brand-mark`).
Keep clear space of one mark-height-quarter around it; never recolour the inside.

## Colour

| Token | Light | Dark | Use |
|---|---|---|---|
| Brand gradient | `#7c5cff → #5b8cff → #22d3ee` | same | mark, primary CTAs, fit bars, highlights (sparingly) |
| Accent | `#6246ea` | `#9b85ff` | links, active states, fit numbers |
| Background | `#f6f6fa` | `#07080c` | page |
| Surface | `#ffffff` | `#0f111a` | cards |
| Text | `#0d0f1c` / `#4a5068` / `#838aa0` | `#eceef6` / `#a3aac0` / `#6c748c` | primary / secondary / muted |
| Good / warn / bad | `#16a34a` / `#b7791f` / `#dc2626` | `#34d399` / `#f5b83d` / `#f87171` | status only |

All tokens are CSS variables in `app/web/assets/brand.css`; dark mode follows the OS unless the user picks one.

## Type

Inter (variable, self-hosted, SIL OFL: `assets/fonts/Inter-LICENSE.txt`). Headlines 700–750 with tight tracking
(-0.035 to -0.045em); body 15px/1.55; numbers use tabular figures.

## Voice

Precise, calm, a little dry. Show the number and how it was made; never hype a model. Prefer "cheaper and better"
over "best"; flag uncertainty ("thin coverage") rather than hide it. Credit data sources by name.
