      Methodology

      Pricing reflects official API rates from each provider as of the last update date. For open-weight models (e.g., Llama), pricing is based on representative API hosting providers. Benchmark scores are sourced from official technical reports, published papers, and trusted third-party evaluations. "Total cost" is calculated as input price + output price per 1M tokens. All benchmarks use publicly reported scores; where multiple evaluation settings exist, we use the most commonly cited configuration.
